Estimate child care fees, subsidies and out-of-pocket costs. Includes multi-child discount logic and responsive UI.

== Description ==

This plugin provides a responsive child care subsidy calculator for Australian families. It allows users to input income, activity hours, children details, and see weekly through yearly estimates.

Use the shortcode [happyhive_calculator] on any page or post.

== Installation ==

1. Upload the plugin folder to /wp-content/plugins/
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Add the shortcode [happyhive_calculator] to a page

== Frequently Asked Questions ==

= How do I add the calculator? =

Add the shortcode [happyhive_calculator] to any page or post.

= Can I change the default income? =

Yes, via Settings → HappyHive Calculator.
