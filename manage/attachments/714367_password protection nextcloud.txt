To perform this task 

We need to create htpasswd file for user mynetedgecloud 
so the command is,

htpasswd -c /etc/httpd/.htpasswd mynetedgecloud

Now it will ask you to put the password two times so provide the password in prompt.

- Then give the proper permission to accessible  by apache ,Commands are below 

chmod 644 .htpasswd
chown apache .htpasswd 

- Then open /home/nextcloud/.htaccess
and add the following lines .
AuthType Basic
AuthName "Restricated"
AuthUserFile /etc/httpd/.passwd
AuthBasicProvider file
Require user mynetedgecloud

RewriteEngine on
RewriteCond %{HTTP_HOST} ^185.185.126.192
RewriteRule (.*) http:///my.netedgetechnology.net/$1 [R=301,L]


Then save the file .

-Now open /etc/httpd/conf/httpd-le-ssl.conf 
Then replace Require all granted to Require all denied .& Restart the httpd 
service httpd restart .
