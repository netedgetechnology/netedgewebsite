(1) The “Strict-Transport-Security” HTTP header is not configured 
****************************************

Solution= Add these follwing line in /etc/httpd/conf/httpd.conf/httpd
and below the Relax <directory>

<IfModule mod_headers.c>
      Header always set Strict-Transport-Security "max-age=15552000; includeSubDomains"
    </IfModule>

(2) The PHP memory limit is below the recommended value of 512MB 
*****************************************************************

Solution = For fixing this error 
First open the file using vim /etc/opt/remi/php73/php.ini

and find memory_limit & and set it memory_limit = 800M

and save the file .For check the value use below command

php73 -i | grep memory_limit

-> then open the second file using vim  /etc/opt/remi/php73/php-fpm.d/www.conf

 Now look for the section of the file shown in the code below and remove the preceding semicolon from all the lines
 
 ;env[HOSTNAME] = $HOSTNAME
;env[PATH] = /usr/local/bin:/usr/bin:/bin
;env[TMP] = /tmp
;env[TMPDIR] = /tmp
;env[TEMP] = /tmp

Then Save the file and restart PHP using this command.

service php73-php-fpm restart

(4) PHP Opcache is not properly configured
*******************************************************************
-> To Resolve this issue, open this file /etc/opt/remi/php73/php.d/10-opcache.ini

and configure the value as per below .

-> Now open the second file  /usr/share/doc/php-common/php.ini-production

and uncomment and modify the values as per bwloe ,then save it.


Then restart the service  
service php73-php-fpm restart



opcache.enable=1
opcache.enable_cli=1
opcache.interned_strings_buffer=8
opcache.max_accelerated_files=10000
opcache.memory_consumption=128
opcache.save_comments=1
opcache.revalidate_freq=1

(5) Your web server is not properly set up to resolve "/.well-known/caldav". Further information can be found in the documentation.
(6) Your web server is not properly set up to resolve "/.well-known/carddav". Further information can be found in the documentation.

-> To resolve this error create nextcloud.conf named file in /etc/httpd/conf.d/nextcloud.conf

and put these two lines 
Redirect 301 /.well-known/carddav https://my.netedgetechnology.net/remote.php/dav
Redirect 301 /.well-known/caldav https://my.netedgetechnology.net/remote.php/dav

Then save it .

Now check the apache is ok using this command.
httpd -t
if the outout says systex ok ,then restart apache ,using service httpd restart.

The error will be gone.

(7) Your data directory and files are probably accessible from the Internet. The .htaccess file is not working. It is strongly recommended that you configure your web server so that the data directory is no longer accessible, or move the data directory outside the web server document root.

-> To resolve this error , first perform some backup precaustion .

copy the "/home/nextcloud",httpd.conf.  folder and store somewhere 

Now check the Document Root ,web root, data directory 

So in our case 
Docuement Root set up in httpd.conf file is /home/nextcloud
Web Root is also /home/nextcloud
data directory is /home/nextcloud/data
,

So we need to create folder named nextcloud in /opt 
commands= 
cd /opt
mkdir nextcloud 
chown apache nextcloud
chgrp apache nextcloud 

Now Move the /home/nextcloud/data to /opt/nextcloud/


Then edit config.php file located in /home/nextcloud/config/config.php

Now find data directory line , then change /home/nextcloud/data to /opt/nextcloud/data


Restart apache using this command
service httpd restart
